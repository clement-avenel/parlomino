## What Parlomino is

Parlomino is an open pictographic code for augmentative and alternative communication (AAC), and the tools to use it. It is not a therapy method: it is designed to serve existing AAC approaches, such as picture exchange, communication books, core vocabulary or visual schedules.

## Status

This is an early version. The drawings are first drafts, being tested with therapists and families. Each pictogram is meant to be understood at a glance by children, and the drawings will change based on these tests.

## Commitment

The Parlomino language (pictograms, grammar and engine) is and will remain open and complete. Services built around it (application, sync, hosted API and MCP) are offered by subscription.

## Contributing

- **Drawings**: follow the [design guidelines](https://github.com/clement-avenel/parlomino/blob/main/docs/design-guidelines.md). Every drawing is checked automatically against the palette, the outline rules and a simplicity budget.
- **Translations**: add labels in your language to the library, and translate this site.
- **Testing with children**: the guidelines describe a short protocol to check that a pictogram is understood.
