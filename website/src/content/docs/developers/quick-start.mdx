The engine is a small TypeScript library, with no DOM and no file access: it runs in browsers, Node, mobile apps and other stacks. The outputs shown on this page are computed by the engine when the site is built.

<Aside type="note" title="Installed from GitHub">
  The package is distributed through [GitHub Releases](https://github.com/clement-avenel/parlomino/releases), not the npm registry. Replace the version in the link to upgrade.
</Aside>

## Errors suggest a fix

The engine never throws on invalid input: it returns the issues, with a suggestion when it can. This makes it easy to use from a form, an API or an LLM.

## Use it from another language

`parlomino/global` (`dist/parlomino.global.js`) is the engine and the library in one file, exposing a `Parlomino` global
with `compose`, `validate`, `search`, `themes`, `jsonSchemas` and `version`.
It only needs a JavaScript engine, without Node, a DOM or file access: [download it](https://github.com/clement-avenel/parlomino/releases/download/v0.1.0/parlomino.global.js), load it in the engine embedded in your language, then call `Parlomino.compose(…)`.
