Le moteur est une petite bibliothèque TypeScript, sans DOM ni accès aux fichiers : il fonctionne dans un navigateur, sous Node, dans une app mobile ou dans d'autres langages. Les résultats affichés sur cette page sont calculés par le moteur au moment de la génération du site.

<Aside type="note" title="Installation depuis GitHub">
  Le paquet est distribué par les [GitHub Releases](https://github.com/clement-avenel/parlomino/releases), pas par le registre npm. Pour changer de version, modifiez-la dans le lien.
</Aside>

## Composer une phrase

Une phrase est une liste de pictos, avec un temps et un point d'interrogation pour toute la phrase. Vous obtenez la bande complète, et chaque picto séparément.

## Les erreurs proposent une correction

Le moteur ne lève jamais d'exception sur une saisie invalide : il renvoie les problèmes, avec une suggestion quand c'est possible. C'est pratique depuis un formulaire, une API ou un LLM.

## L'utiliser depuis un autre langage

`parlomino/global` (`dist/parlomino.global.js`) contient le moteur et la bibliothèque en un seul fichier, qui expose un objet global `Parlomino`
avec `compose`, `validate`, `search`, `themes`, `jsonSchemas` et `version`.
Il suffit d'un moteur JavaScript, sans Node, DOM ni accès aux fichiers : [téléchargez-le](https://github.com/clement-avenel/parlomino/releases/download/v0.1.0/parlomino.global.js), chargez-le dans le moteur intégré à votre langage, puis appelez `Parlomino.compose(…)`.
