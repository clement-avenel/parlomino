## Principles

<CardGrid>
  <Card title="Simple for children" icon="heart">
    Concrete drawings, few strokes, the same place for each element. Every drawing is checked automatically against a simplicity budget.
  </Card>
  <Card title="Composable" icon="puzzle">
    Four building blocks and five zones are enough to read and build any pictogram.
  </Card>
  <Card title="Open" icon="open-book">
    Free to use, share and adapt, including in commercial products. The language will remain open and complete.
  </Card>
  <Card title="International" icon="translate">
    Drawings contain no text. Labels exist per language, starting with English and French.
  </Card>
</CardGrid>

<Aside type="note" title="Early version">
  The drawings are first drafts, being tested with therapists and families. Parlomino is a pictographic code and tools: it is designed to serve existing AAC approaches, not to replace them.
</Aside>
